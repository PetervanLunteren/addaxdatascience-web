what it is

One system, from camera to conclusion

Fully self-hosted, so your data stays yours.

A connected platform

Every camera reports to one place. Maps, charts, camera health and a searchable image database, live in the browser and shared with your whole team.

An early warning system

Elephants near crops, wolves near livestock, people where they should not be: a Telegram message arrives seconds after the photo is taken.

Autonomous monitoring

You see what your cameras saw without waiting for a field visit. Photos arrive over the cellular network and the AI works around the clock.

How it works

  1. 1

    A camera takes a photo

    A cellular camera trap detects movement and sends the photo straight from the field, over FTPS.

  2. 2

    Your server receives it

    The image lands on your own server. Your data stays yours, on hardware you control.

  3. 3

    AI identifies the animal

    The AI finds the animals in the photo and works out which species they are, seconds after capture.

  4. 4

    You get answers

    The dashboard updates and, if a species is on your alert list, an alert goes out straight away.

before you start

Built for people who can run a server

Connect is self-hosted. That is what keeps it free and keeps your data yours, but it also means someone has to set up a server from the command line. If that sounds like fun, you will be fine. If it does not, we can set it up and run it for you.

  • A server running Ubuntu, from any provider
  • A domain name pointing at that server
  • Any camera trap that can upload over FTPS
  • A SIM card with a data plan for each camera
  • Comfort with SSH, DNS and running a few commands
$ git clone https://github.com/PetervanLunteren/AddaxAI-Connect.git
$ cd AddaxAI-Connect
$ ansible-playbook -i ansible/inventory.yml ansible/playbook.yml

These commands build the entire system on your server: database, AI workers, web interface and SSL certificate. It takes 30 to 60 minutes, and the deployment guide walks through every step.

Common questions

How is this different from AddaxAI?

AddaxAI is a desktop app: you bring photos to your own computer and analyse them there. AddaxAI Connect is its online sister: cameras send photos to your own server by themselves, and the results appear in a shared web dashboard with real-time alerts. Many teams use both.

Do I need to be a developer?

For daily use, no: the dashboard is a normal website. For the one-time setup, yes, a bit: you will run a few commands over SSH and point a domain at your server. The deployment guide covers it, and if it is not your thing, we can do it for you.

What does it really cost?

The software is free. You pay for the hardware around it: a server (example: ~$48 per month), cameras, SIM data plans and a domain. The planning tool gives an itemized estimate for your setup.

Which cameras work?

Any camera trap that can upload over FTPS, which out in the field usually means a cellular one. Tested models include the Willfine 4.0T CG, the Swift Enduro 4.0PCG-R and INSTAR; other models can work through a custom camera profile. The docs keep the current list, along with what a camera needs to be compatible.

Can I use cameras that are not connected?

Yes. A project admin can upload a folder of images straight from an SD card and assign it to a camera, and those photos run through the same detection, classification, dashboards and exports as everything else. The server is sized for photos arriving a few at a time, not thousands at once, so a full card takes a while to work through. Connected cameras always go first. A bulk upload fills the gaps in the background and never delays a real-time alert.

Which species can it recognise?

MegaDetector finds the animals, then DeepFaune or SpeciesNet names the species. Other models from the AddaxAI model zoo can be added on request, as long as their licence allows it: some are free for any use, others are non-commercial. Ask if you need one for your region.

Can I use it commercially?

Yes, but check the licences. Connect itself is MIT-licensed. The models it runs have their own: SpeciesNet is Apache 2.0 and the DeepFaune weights are CC BY-SA 4.0. All three allow commercial use and ask for attribution, and CC BY-SA also asks that anything you build on the model itself is shared on the same terms. Models added later from the AddaxAI model zoo have their own licences again, and some of those are non-commercial.

Where do my images live?

On your own server, and nowhere else. You choose the provider and the country it runs in, you hold the keys, and nothing is shared with anyone. Detected people and vehicles can be blurred automatically for privacy.

Can you set it all up for me?

Yes. We can plan the project with you, source and configure the cameras, run the server and keep it updated. Start with the planning tool or get in touch.
